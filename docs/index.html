A SMALL TOOL. A CLEARER PICTURE.

From ban to heads-up.
Without the busywork.

Connect Fail2Ban’s action system to the services you use. Add context, choose your channels, and keep moving.

01 / DETECT
⌁

Fail2Ban does its thing.

A jail bans or unbans an IP. The notifier runs as a Fail2Ban action, fitting into your existing setup.

02 / ENRICH
◎

Give the event context.

Add optional GeoIP details with online providers or local MaxMind GeoLite2 databases. Persistent caching saves repeat lookups.

03 / DELIVER
↗

Send it somewhere useful.

Route notifications to your chosen connectors. Customize message templates and retry failed deliveries.

BUILT FOR THE WAY YOU RUN THINGS

Read the documentation ↗
01

Start with a conversation.

The interactive setup wizard walks you through configuration, connectors, and a test notification.

02

Your infrastructure, your choices.

Use HTTPS GeoIP services, go offline with GeoLite2, or skip enrichment entirely. Alerts still work when geographic data is unavailable.

03

Make the last mile your own.

Use the included connectors or write your own. Flexible templates and custom webhooks let you shape the message.

QUICK START bash
01

Install the latest release

curl -sSL https://raw.githubusercontent.com/eyeskiller/fail2ban-notifier/refs/heads/main/install.sh | sudo bash
02

Run the interactive setup

sudo fail2ban-notify -setup

Requires Linux and Fail2Ban. The installer uses sudo to install the binary, configuration, and connectors.
